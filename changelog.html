🚀 Latest Release Major Release

v1.0.0

September 25, 2026
New Features
  • Initial stable launch of Coursera DL desktop client
  • Native Tauri v2 and Rust core engine for ultra-low memory usage and native speed
  • High-resolution video segment downloader supporting 1080p and 720p streams
  • Automated extraction and downloading of multilingual VTT and SRT subtitles
  • Lecture notes, reading materials, and PDF slides downloading
  • One-click batch specialization discovery and nested course downloader
  • Local workstation session cookie (CAUTH) authentication with zero remote telemetry
  • Human-mimicking smart request throttling with randomized pacing
  • One-line automated shell installers for macOS, Linux, and Windows PowerShell
Fixes & Improvements
  • Resolved expired session recovery and network timeout chunk resumption
  • Fixed macOS DMG mount quarantine permissions on Apple Silicon and Intel
