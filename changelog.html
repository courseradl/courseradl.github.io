🚀 Latest Release Patch Release

v1.0.1

September 26, 2026
New Features
  • Native Login with Coursera flow with a secure in-app authentication window and automatic session handoff
  • Automatic capture of Coursera HttpOnly CAUTH and CSRF session cookies from the native WebView cookie store
  • Dual login experience with direct Coursera authentication and an expandable cookie-based fallback
  • Broader manual cookie import support for Netscape cookies.txt, Cookie-Editor JSON, and raw Cookie header formats
  • Refined authentication interface with the official Coursera mark, direct login flow, verification feedback, and clear cancellation controls
  • Sign-out confirmation dialog with complete local session and WebView storage cleanup
  • New SEO-optimized product website in the docs directory with responsive app-themed branding and release links
Fixes & Improvements
  • Reliable interception of HttpOnly CAUTH cookies that are unavailable through document.cookie
  • Correct Coursera parent-domain cookie matching for .coursera.org sessions opened on www.coursera.org
  • Prevented premature login completion when only a CSRF cookie or dashboard redirect was detected
  • WebView login cancellation now resolves immediately instead of remaining active until timeout
  • Improved parsing of semicolon-separated cookies and Cookie-Editor exports
Major Release

v1.0.0

September 25, 2026
New Features
  • Initial Release of Coursera DL desktop application (Tauri v2 + Rust + React 19 + TypeScript)
  • High-performance native downloading engine with concurrent workers and memory-safe streaming
  • Full support for multi-course specializations and individual course material preservation
  • Batch specialization enrollment with automatic course progress discovery
  • Course Slug downloader for direct on-demand course downloading
  • Comprehensive asset preservation: HD videos (720p/1080p), lecture notes, reading assets, subtitles (.vtt/.srt), and course PDFs
  • Local Netscape/Cookie-Editor cookie-based authentication with zero external credential leakage
  • Authenticated user profile enrichment (name, email, profile photo, and initial monograms)
  • Human-mimicking smart request throttling with randomized pacing intervals between module downloads
  • Stale-While-Revalidate caching architecture for enrolled course catalog and module hierarchy
  • Live download progress tracking, pause/resume capabilities, and file system explorer integrations
  • Modern studio-inspired UI with authentic Coursera color palette, light/dark themes, and animated splash logo
  • Cross-platform support for Windows, macOS (Universal / Apple Silicon & Intel), and Linux
Fixes & Improvements
  • Specialization directory depth resolution and nested folder organization
  • Transparent rounded squircle app icons for desktop bundles and window managers
  • Full multi-user session isolation with clean logout and cookie purge
